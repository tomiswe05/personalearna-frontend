# Design

## Color Palette

| Color | Hex | Role |
|---|---|---|
| ⬛ | `#000000` | Text — primary text color |
| ⬜ | `#FFFFFC` | Surface — page/card backgrounds |
| 🟫 | `#BEB7A4` | Secondary / neutral — muted backgrounds, borders, supporting UI |
| 🟥 | `#FF3F00` | Primary / Emphasis — primary buttons, links, active states, key CTAs |
| 🟧 | `#FF7F11` | Hover accent — hover/active states on primary elements |
